# Java 복습 1 — 지출 합계

`ExpenseSummary.java`는 record, List, Stream, BigDecimal을 사용하는 작은 독립 실행 예제입니다. 프레임워크 없이 Java 언어와 표준 라이브러리부터 다시 읽어 봅니다.

```powershell
javac ExpenseSummary.java
java ExpenseSummary
```

## 직접 해볼 과제

1. `FOOD` 카테고리의 총액만 계산합니다.
2. 날짜별로 지출을 묶고 날짜순으로 출력합니다.
3. 금액이 0 이하인 입력을 막고 오류 메시지를 정합니다.
4. Stream 대신 반복문으로 같은 결과를 만들어 차이를 설명합니다.

과제를 끝내면 예제 입력, 실제 출력, 고민한 점을 학습 기록에 남깁니다.
