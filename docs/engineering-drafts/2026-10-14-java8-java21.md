## Java를 다시 공부하기하면서.

이력서를 정리하면서 아이맥스소프트에서 Java와 JSP로 개발했던 경험을 다시 한번 살려볼 생각을 하게 되었다. 최근에는 프론트엔드 업무가 많았고, Java는 다른 개발자가 작성한 코드를 확인하는 정도로 실무에서 사용을 했었는데, 예전에 사용했던 언어라고 해도 지금 다시 직접 코드를 작성하려니 복습이 많이 필요한 상황이 되었다.

우선 Java를 다시 익히고, 그다음 Spring으로 API를 만들어 보려고 하는데, 처음부터 큰 서비스를 만들기보다는 작은 예제를 직접 바꾸고 실행해 보는 방식으로 진행하고 있다.

## 예제를 보고도 낯선 문법이 가득.

Codex가 처음 만들어 준 예제는 지출 목록의 전체 금액과 카테고리별 합계를 계산하는 코드였다. 기능은 단순했지만, `record`, `List.of()`, `stream()`처럼 아이맥스소프트에서 사용하던 실무 함수들과 너무 다른 함수들이 많이 나왔다.

아이맥스소프트 기준은 Java 8이었고, 지금 공부할 환경은 JDK 21이다. 처음에는 버전이 바뀌면서 문법과 함수가 많이 달라진 것으로 생각했다. 그래서 예전에 개발하던 방식과 현재 예제를 나란히 볼 수 있으면 좋겠다고 생각했다.

## 같은 기능을 두 가지 방식으로 만들다.

Codex에 예전 코드의 작성 방식을 참고해, 같은 기능을 Java 8 방식과 Java 21 방식으로 각각 만들어 달라고 요청했다. 이전 회사 샘플 소스를 기준으로 가상의 학습자와 점수로 성적을 집계하는 독립 예제를 준비했다.

Java 8 쪽은 일반 클래스에 생성자와 getter를 작성하고, `for`문과 `if`로 합계와 통과 여부를 계산한다. 다른 쪽은 `record`로 데이터를 선언하고, Stream으로 점수를 꺼내 더하거나 조건에 맞는 이름을 모은다.

처음부터 양쪽의 입력과 결과를 같게 맞췄다. 그래야 내가 값을 바꿨을 때 계산 결과를 비교하고, 같은 일을 코드에서 어떻게 다르게 표현하는지 볼 수 있기 때문이다.

두 예제 모두 설치한 JDK 21에서 실행한다. Java 8 쪽은 `--release 8`로 컴파일해 Java 8의 문법과 표준 API 범위를 확인한다. 예전 서버 환경 전체를 재현한 것은 아니다.

## Stream은 Java 8에도 있었다

이번에 가장 먼저 구분하게 된 것은 내가 예전에 사용하지 않았던 기능과, 이후 버전에서 새로 생긴 기능이 다르다는 점이다.

Stream과 람다, 메서드 참조, `forEach`는 Java 8에도 있다. 당시 업무에서 접하지 않았기 때문에 낯설었던 것이다. 반면 `record`나 `Stream.toList()`는 Java 8 이후에 추가된 기능이다.

지금 예제에서는 `filter`가 `if` 조건에 해당하고, `map`은 필요한 값을 꺼내 다음 처리로 넘기는 역할을 한다. `mapToInt(...).sum()`은 반복문 안에서 점수를 누적하던 부분과 연결해서 볼 수 있다. 모든 코드를 한 번에 외우기보다는 익숙한 코드와 한 부분씩 비교하려고 한다.

함수 설명은 Java 파일의 해당 코드 옆에 주석으로 남기고, 설명이 길어지는 용어는 별도 Markdown 파일로 정리해 달라고 요청했다. 코드를 다시 열었을 때 설명도 함께 볼 수 있도록 하기 위해서다.

## AI가 만든 코드에서 내가 고치는 코드로

이번에는 예제를 처음부터 혼자 만든 것은 아니다. Codex가 예제를 준비했고, 나는 양쪽 파일의 입력을 수정하고 점수 출력 코드를 추가했다. 컴파일과 실행 결과도 Codex와 함께 확인했다.

아직 실행 결과를 확인하는 단계이고, Stream이나 최신 문법을 충분히 이해했다고 말할 정도는 아니다. 그래서 앞으로도 같은 방식으로 작은 수정을 해 보려고 한다. 먼저 통과 기준을 바꾸거나 학습자를 추가하고, 그다음 미통과 이름 출력과 잘못된 점수 처리까지 이어갈 생각이다.

공부 기록에는 어떤 파일이 추가됐는지만 남기기보다, 내가 무엇이 낯설었고 무엇을 직접 바꿨는지, 실행 결과에서 어떤 점을 확인했는지도 함께 적어 두려고 한다.

## 이번에 비교한 핵심 코드

같은 성적 입력으로 데이터 선언, 합계, 조건 선택, 이름 목록, 출력을 비교했다. 아래 코드는 전체 프로그램에서 핵심 부분만 발췌한 것이다.

| 공부한 부분 | Java 8 예제 | Java 21 예제 |
| --- | --- | --- |
| 데이터 한 건 | 일반 클래스·생성자·getter | record·자동 접근자 |
| 점수 합계 | for문으로 누적 | mapToInt → sum |
| 통과 이름 | if → 이름을 목록에 추가 | filter → map → toList |
| 점수 출력 | List.forEach | Stream.forEach |

### 1. 학습자 한 명을 표현하기

**Java 8 — 필드, 생성자, getter를 직접 작성**

```java
static class Grade {
    private final String studentName;
    private final int score;

    Grade(String studentName, int score) {
        this.studentName = studentName;
        this.score = score;
    }

    public String getStudentName() { return studentName; }
    public int getScore() { return score; }
}
// 읽기: grade.getScore()
```

**Java 21 — record로 같은 데이터를 선언**

```java
// 생성자·접근자 등을 자동 제공한다. record는 Java 16부터 정식 제공.
record Grade(String studentName, int score) {}
// 읽기: grade.score() — get 접두사 없이 값을 읽는다.
```

### 2. 같은 입력에서 합계와 통과 이름 구하기

**두 버전에서 직접 수정한 입력**

```java
List<Grade> grades = new ArrayList<>();
grades.add(new Grade("학습자A", 80));
grades.add(new Grade("학습자B", 65)); // 55 → 65로 직접 수정
grades.add(new Grade("학습자C", 75));
// 통과 기준: PASS_SCORE = 60
```

**Java 8 — 순회·누적·조건 분기를 직접 작성**

```java
int totalScore = 0;
List<String> passedNames = new ArrayList<>();

for (int i = 0; i < grades.size(); i++) {
    Grade grade = grades.get(i);
    totalScore += grade.getScore(); // 한 명씩 점수를 더한다.

    if (grade.getScore() >= PASS_SCORE) { // 60점 이상만 선택
        passedNames.add(grade.getStudentName()); // 이름을 모은다.
    }
}
```

**Java 21 — 처리 단계를 연결해서 작성**

```java
int totalScore = grades.stream()
    .mapToInt(Grade::score) // 점수 int를 꺼낸다.
    .sum();               // 80 + 65 + 75 = 220

List<String> passedNames = grades.stream()
    .filter(grade -> grade.score() >= PASS_SCORE) // 조건: if와 대응
    .map(Grade::studentName)                     // Grade → 이름 String
    .toList();                                  // 이름들을 목록으로 모은다.
```

`Grade::score`는 이 위치에서 `grade -> grade.score()`와 같은 동작을 뜻한다. `toList()`는 Java 16부터 제공되며 결과 목록은 수정할 수 없다. Java 8 예제의 `ArrayList`는 수정할 수 있어, 출력이 같아도 결과 목록의 성질은 다르다.

### 3. 직접 추가한 점수 출력

```java
// Java 8: 목록 자체를 순회하며 getter로 점수를 읽는다.
grades.forEach(grade -> System.out.print(grade.getScore() + ", "));

// Java 21: Stream으로 순회하며 record 접근자로 점수를 읽는다.
grades.stream().forEach(grade -> System.out.print(grade.score() + ", "));
```

`->`는 원소 하나를 받아 수행할 동작을 적는 람다 문법이다. 단순 출력은 Stream 없이 `List.forEach`로도 가능하다. `print()`에는 줄바꿈이 없어 점수 뒤에 다음 문구가 붙었다.

### 4. 두 버전에서 확인한 결과

```text
학습자 수: 3
점수 합계: 220
80, 65, 75, 통과: 3
미통과: 0
통과 학습자: [학습자A, 학습자B, 학습자C]
```

Stream·람다·메서드 참조·forEach는 Java 8에도 있다. 이번 비교는 익숙한 반복문 방식과 최신 예제의 표현 방식을 비교한 것이며, Stream 자체가 Java 21에서 새로 생긴 기능은 아니다.
